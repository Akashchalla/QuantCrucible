# Three-minute demo

0:00 — “Filing Edge asks a question every trading team should ask: does this idea deserve capital? It can produce a documented no-trade decision.” Show the beginner explanation and research-only decision.

0:25 — Open Filing evidence. Show the exact 8-K accession, filing date and assumed availability. Run or show Gemini's cached explanation. Point to a verified source quote. Explain that AI never generates the trading signal.

0:55 — Return to Development. Show the fixed 21-session comparison, all horizons and a cost/delay cell. Explain bid, ask and strike collateral in one sentence each. Show Original pilot: the revised method and original findings are both disclosed, not erased.

1:25 — Open Held-out test. “The method was frozen before this window. The relative result is positive but comes from only five pairs. The event trades themselves lost money. We do not call that a proven edge.”

1:50 — Show the account curve. One position survived the capital and liquidity rules and lost $795.80 on $1 million. Open assumptions to show missing-quote reserves and capacity exclusions. Open the downside calculator to demonstrate assignment risk.

2:15 — Data infrastructure: load live Timescale aggregates and saved research runs. Explain that the database is serving precomputed daily activity, not merely storing a connection string.

2:35 — Generate/play the ElevenLabs briefing and open its exact transcript. Explain accessibility and deterministic numerical grounding.

2:50 — Show the judge notebook and PDFs. “A judge can replace the dates and rerun the same code using only a Massive key. Our product is an evidence trail from hypothesis to allocation decision.”

If presenting the hosted replay, explicitly say it contains saved verified API outputs. Use the local authenticated server for live sponsor calls. Do not claim guaranteed fills, causality, profitability, or institutional production readiness.
